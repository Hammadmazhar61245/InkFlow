# InkFlow ✍️

**InkFlow** is a lightweight, distraction-free Android notepad app designed for drawing notes, quick sketches, and freehand ideas directly with your finger. Built with a clean and responsive canvas, it lets you capture thoughts naturally without unnecessary clutter or complicated toolbars.

## ✨ Features

* **Smooth Finger Drawing:** Responsive touch-tracking engineered for natural handwriting and freehand sketching.
* **Distraction-Free Canvas:** Minimalist interface that keeps the focus entirely on your strokes.
* **Instant Note-Taking:** Zero setup friction—open the app and start drawing immediately.
